# Тіл білгірлері LIVE — толық пакет

Бұл пакет GitHub + Render үшін дайын.

## Ішінде
- app.py — ойынның негізгі коды
- requirements.txt — Python кітапханалары
- Procfile — іске қосу командасы
- render.yaml — Render конфигурациясы
- .gitignore — уақытша файлдарды елемеу
- README_KZ.md — осы нұсқаулық

## GitHub-қа жүктеу
1. Репозиторийде ескі app.py, app (2).py, app (3).py сияқты артық файлдар болса, өшіріңіз.
2. Осы папкадағы файлдардың бәрін GitHub репозиторийінің түбіріне жүктеңіз.
3. Commit changes басыңыз.

## Render
Build Command:
pip install -r requirements.txt

Start Command:
gunicorn app:app

Содан кейін:
Manual Deploy -> Deploy latest commit

## Ойын логикасы
1-кезең: 5 сұрақ
2-кезең: 4 сұрақ
3-кезең: 3 тапсырма
4-кезең: 4 тапсырма
5-кезең: 1 тапсырма
6-кезең: 3 тапсырма
7-кезең: 1 тапсырма
8-кезең: суперфинал

1-кезеңде сұрақтар 1/5 -> 2/5 -> 3/5 -> 4/5 -> 5/5 болып кезекпен ашылады.
Сұрақтар орыс тілді 7–9 сынып оқушыларына арналған қазақ тілі Т2 деңгейінде жеңілдетілген.
