# Тіл білгірлері LIVE — Render-ге дайын

1. Осы папкадағы файлдарды GitHub репозиторийіне жүктеңіз.
2. Render-де New + → Web Service таңдаңыз.
3. GitHub репозиторийін таңдаңыз.
4. Build Command: `pip install -r requirements.txt`
5. Start Command: `gunicorn app:app`
6. Deploy басыңыз.
7. Render сізге `https://...onrender.com` түріндегі тұрақты сілтеме береді.

Сайтта мұғалім «Жаңа бөлме ашу» арқылы жеке 5 таңбалы код алады. Оқушыларға дайын `/play/КОД` сілтемесі жіберіледі. Бір сайтты бірнеше мұғалім бөлек бөлмелермен пайдалана алады.

Ескерту: SQLite файлы Render сервисі қайта іске қосылғанда сақталмауы мүмкін. Сабақ барысындағы LIVE сайысқа жарайды; ұзақ мерзімді нәтижелер керек болса, кейін PostgreSQL қосқан дұрыс.
